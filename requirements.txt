# On Linux (Streamlit Cloud) the default PyPI `torch` is the CUDA build, ~2.5GB, which
# overruns the Cloud disk limit. The `+cpu` local version only exists on PyTorch's own
# index, so naming it forces the small CPU wheel. On Windows/macOS the PyPI wheel is
# already CPU-only and has no `+cpu` suffix, hence the marker split.
